# Controlled RepoGuard sample reports

All three samples were generated by RepoGuard itself using deliberately constructed local fixtures. No public website is alleged to be vulnerable.

- **remote-fixture/**: temporary loopback HTTP server with readable Git HEAD/config, SVN entries, and `.gitignore`. Three VCS metadata exposures; `.gitignore` alone is informational. No Git objects fetched.
- **local-native/**: native scan of synthetic commits containing fake OAuth/database values and a private-key marker. These files were subsequently deleted. Also shows `.env`/staging history, an unmerged feature ref, and fictional author domain `internal.example`.
- **local-gitleaks/**: the same history scanned with real Gitleaks v8.30.1 plus native checks. Includes a deliberately fake token-shaped fixture. Values and raw matches are excluded.

Paths, ports and commit IDs identify temporary fixtures and will vary on regeneration. Those fixtures no longer exist. Each folder includes `git_audit_report.json` and `git_audit_summary.txt`.

Regenerate using the command in the main README. Tests with no optional real Gitleaks binary still run the mocked adapter checks but do not regenerate `local-gitleaks/`.
